## Discrete Math

Repository này hiện có thêm một module **Discrete Mathematics standalone** tại:

```text
discrete-local/
```

Module này được tách riêng để học và ôn luyện Discrete Math, không cần chạy Study_Hub.

### Chạy nhanh

Yêu cầu: Git + Node.js/npm.

```bash
git clone https://github.com/huybndc/Learning_Python.git
cd Learning_Python/discrete-local
npm install
npm run dev
```

Mở:

```text
http://localhost:5191/
```

Hướng dẫn đầy đủ cho người mới về Git, clone, pull, push, fork, cài đặt và xử lý lỗi nằm trong:

```text

```
