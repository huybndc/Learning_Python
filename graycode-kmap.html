Gray code & Karnaugh map

Công cụ trực quan hỗ trợ môn Logic Circuit — chạy hoàn toàn offline trong trình duyệt.

1. Bảng Gray code

Bit đỏ gạch chân là bit đổi so với hàng ngay trên (hàng đầu so với hàng cuối — vòng tròn).

2. Xây dựng bằng “reflect and prefix”

Gray n bit = (Gray n−1 bit, thêm tiền tố 0) nối với (Gray n−1 bit lật ngược, thêm tiền tố 1). Chỗ nối ở giữa là hai bản sao của cùng một chuỗi n−1 bit, nên chỉ khác nhau đúng ở bit tiền tố.

4. Vì sao K-map dùng thứ tự Gray?

Trong K-map, hai ô kề nhau phải khác nhau đúng 1 biến — khi đó ghép chúng lại thì biến đó bị triệt tiêu: A′BC + ABC = BC(A′+A) = BC.

Nếu dán nhãn theo thứ tự nhị phân thường (00, 01, 10, 11) thì bước 01→10 đổi tới 2 bit ⇒ hai ô kề nhau không gộp được. Thứ tự Gray (00, 01, 11, 10) đảm bảo mọi bước chỉ đổi 1 bit, và vì Gray là chu trình khép kín nên cột cuối cũng kề cột đầu ⇒ sinh ra các nhóm wrap-around (ví dụ 4 góc của K-map 4 biến).

Nói cách khác: K-map chính là hình vẽ của siêu khối n chiều trải phẳng, và Gray code là cách trải giữ nguyên quan hệ kề.
